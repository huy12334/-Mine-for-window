# Hướng dẫn cài đặt

## 1. Tải về
- Nhấn vào nút **Download ZIP** để tải toàn bộ dự án về máy.

## 2. Giải nén
- Giải nén file ZIP vừa tải xuống.

## 3. Mở thư mục trong PowerShell
- Mở thư mục vừa giải nén.
- Giữ phím **Shift** và nhấn **chuột phải** vào khoảng trống trong thư mục.
- Chọn **"Open PowerShell window here"** (hoặc **"Mở cửa sổ PowerShell tại đây"**).

## 4. Chạy script cài đặt
- Trong cửa sổ PowerShell, nhập lệnh sau và nhấn **Enter**:

```powershell
.\setup.ps1
```

## 5. Hoàn tất
- Đợi script chạy xong và làm theo các hướng dẫn hiển thị trên màn hình (nếu có).
